プライバシーポリシー

サトリの手帖（https://satori-techo.github.io/）で集める情報と、その使い方を書きます。

記事が開かれた数

人気の記事を並べるために、記事ごとに、開かれた数を日ごとに数えています。数えるのは「どの記事が、その日に何回開かれたか」だけで、名前・メールのアドレス・IP アドレスなど、読んだ人が分かる情報は残しません。数は 22 日たつと消えます。

YouTube の連携

運営者は、自分の YouTube のチャンネル「サトリの手帖」の説明・再生リスト・動画を整えるためだけに、Google の YouTube Data API を使います。読む人の Google アカウントの情報を集めたり、使ったりすることはありません。

Cookie と外のサービス

このサイトは広告を出さず、読む人を追いかける Cookie も使いません。サイトは GitHub Pages で、開かれた数は Cloudflare で動かしています。

変えるとき

この中身を変えるときは、このページを書き直します。
